# GW 生产快照（2026-11-26）

这个分支是 xiaomanhome 网关**线上实际运行**的代码快照，**不是** main（v0.4.0）的延续，
两者的 `server.mjs` / `dashboard.html` 不同源：

- 线上：基于 2026-10-21 分发的 188KB 版本 + 本地补丁（当前 205KB / 110KB）；
- main：v0.4.0（360KB / 178KB），已重写统计、额度、安全与面板结构。

## 本快照包含

- `feat(forecast)`：「周期用量预测」模块 —— `GET /api/stats/go-forecast?tz=480`
  - 逐小时桶按峰谷价计价后折本地日，画实际累计 + 预测虚线 + 区间；
  - 纵轴为额度百分比（0–120%），100% 线标 `plan 100%`，预测越限换深红、可越出画布；
  - 「已花」以官方 percent 为准，网关估算只作校准底数（`gateway_spent` / `scale` / `caliber`）；
  - `GO_PEAK` 里 deepseek 的 cap 按官方文档由 60 改为 100。
- 面板页脚移除已下线的 `status.`（原监控页）链接。

## 合并提示

**不要**把它合进 main：会把 v0.4.0 约 150KB 改动整体回退。
要长期保留该功能，正确做法是按 main 的 `computeGoCycles` / `goModelCost` 重写一版。
